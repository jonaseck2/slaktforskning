# Places: API, PlacePicker, and Views

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the full places layer — API, IPC, MCP tools, PlacePicker component, and UI views — so that events can be linked to structured place records and places are manageable through both the UI and the MCP server.

**Architecture:** The `places` table already exists in the schema with the full structure (`name`, `normalized_name`, `place_type`, `parent_place_id`, `latitude`, `longitude`, `date_from`, `date_to`, `notes`). This plan adds everything above the schema: a `src/api/places.ts` module, IPC handlers, preload bindings, a `PlacePicker` Vue component (like `PersonPicker` but for places), a fix to `EventForm` which currently has a `place_name` input that is completely ignored (never writes `place_id`), a `PlacesView` list, a `PlaceDetailView`, and MCP tools.

**Tech Stack:** SQLite via node-sqlite3-wasm, TypeScript, Vue 3 Composition API, Vitest unit tests, MCP server (@modelcontextprotocol/sdk).

## GEDCOM-X Place Model — What We Support vs. What's Missing

GEDCOM-X `PlaceDescription` defines:
- ✅ **names** — list of TextValue (language-tagged names) — current model: single `name` field
- ✅ **place type** — enumerated — covered by `place_type`
- ✅ **parent hierarchy** — `parent_place_id` covers this
- ✅ **lat/lon** — covered
- ✅ **temporal validity** — `date_from`/`date_to` covered
- ❌ **multi-language names** — e.g. "Stockholm" (sv) + "Stockholm" (en) + "Stokholmas" (lt) — not in schema
- ❌ **place identifiers** — e.g. GeoNames ID `2673730`, Wikidata Q1754 — not in schema
- ❌ **spatialDescription** — KML/GIS shape reference — not needed for MVP

Multi-language names and external identifiers are deferred. This plan implements the single-name model with hierarchy and optional lat/lon, which is what GEDCOM 5.5.1 PLAC tags map to.

**GEDCOM 5.5.1 PLAC format:** Hierarchical, comma-separated: `"Björkvik, Rönö härad, Södermanland, Sverige"`. On import, this becomes one Place per unique name string; hierarchy is inferred from the order (last = country). On export, the `name` field is used as-is.

- [ ] **Step 4: Implement src/api/places.ts**

```typescript
import { Database } from 'node-sqlite3-wasm';
import { Place } from './types';

function normalize(name: string): string {
  return name.toLowerCase().trim().replace(/\s+/g, ' ');
}

export function createPlace(
  db: Database,
  data: {
    name: string;
    place_type?: Place['place_type'];
    parent_place_id?: string | null;
    latitude?: number | null;
    longitude?: number | null;
    date_from?: string | null;
    date_to?: string | null;
    notes?: string;
  }
): Place {
  const id = crypto.randomUUID();
  db.prepare(`
    INSERT INTO places (id, name, normalized_name, place_type, parent_place_id, latitude, longitude, date_from, date_to, notes)
    VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?)
  `).run([
    id, data.name, normalize(data.name),
    data.place_type ?? null, data.parent_place_id ?? null,
    data.latitude ?? null, data.longitude ?? null,
    data.date_from ?? null, data.date_to ?? null,
    data.notes ?? '',
  ]);
  return getPlace(db, id)!;
}

export function getPlace(db: Database, id: string): Place | null {
  return (db.prepare('SELECT * FROM places WHERE id = ?').get([id]) as Place | undefined) ?? null;
}

export function listPlaces(db: Database): Place[] {
  return db.prepare('SELECT * FROM places ORDER BY name ASC').all([]) as Place[];
}

export function searchPlaces(db: Database, query: string): Place[] {
  const q = `%${normalize(query)}%`;
  return db.prepare(
    'SELECT * FROM places WHERE normalized_name LIKE ? ORDER BY name ASC LIMIT 20'
  ).all([q]) as Place[];
}

export function updatePlace(
  db: Database,
  id: string,
  data: Partial<Omit<Place, 'id' | 'normalized_name'>>
): Place | null {
  const existing = getPlace(db, id);
  if (!existing) return null;
  const name = data.name ?? existing.name;
  db.prepare(`
    UPDATE places SET
      name = ?, normalized_name = ?, place_type = ?,
      parent_place_id = ?, latitude = ?, longitude = ?,
      date_from = ?, date_to = ?, notes = ?
    WHERE id = ?
  `).run([
    name, normalize(name),
    data.place_type ?? existing.place_type,
    data.parent_place_id ?? existing.parent_place_id,
    data.latitude ?? existing.latitude,
    data.longitude ?? existing.longitude,
    data.date_from ?? existing.date_from,
    data.date_to ?? existing.date_to,
    data.notes ?? existing.notes,
    id,
  ]);
  return getPlace(db, id);
}

export function deletePlace(db: Database, id: string): boolean {
  return db.prepare('DELETE FROM places WHERE id = ?').run([id]).changes > 0;
}

/**
 * Used during GEDCOM import: find an existing place by normalized name or create it.
 */
export function findOrCreatePlace(db: Database, name: string): Place {
  const norm = normalize(name);
  const existing = db.prepare('SELECT * FROM places WHERE normalized_name = ? LIMIT 1').get([norm]) as Place | undefined;
  if (existing) return existing;
  return createPlace(db, { name: name.trim() });
}
```

- [ ] **Step 1: Create PlacePicker.vue**

PlacePicker is modelled on PersonPicker: debounced search, dropdown of results, "Create new" option when no match.

```vue
<template>
  <div class="place-picker">
    <input
      type="text"
      v-model="query"
      :placeholder="placeholder || $t('places.searchPlaceholder')"
      @input="onInput"
      @focus="showDropdown = true"
      @blur="onBlur"
      autocomplete="off"
    />
    <div v-if="showDropdown && (results.length > 0 || query.length > 1)" class="dropdown">
      <div
        v-for="place in results"
        :key="place.id"
        class="dropdown-item"
        @mousedown.prevent="select(place)"
      >
        <span class="place-name">{{ place.name }}</span>
        <span v-if="place.place_type" class="place-type">{{ $t('placeTypes.' + place.place_type) }}</span>
      </div>
      <div
        v-if="query.length > 1 && results.every(r => r.name.toLowerCase() !== query.toLowerCase())"
        class="dropdown-item create-new"
        @mousedown.prevent="createNew"
      >
        {{ $t('places.createNew', { name: query }) }}
      </div>
    </div>
  </div>
</template>

<script setup lang="ts">
import { ref, watch } from 'vue';
import { useI18n } from 'vue-i18n';

declare const window: Window & {
  api: Record<string, Record<string, (...args: unknown[]) => Promise<unknown>>>;
};

interface PlaceRow { id: string; name: string; place_type: string | null; }

const props = defineProps<{
  modelValue: string | null;
  placeholder?: string;
}>();
const emit = defineEmits<{
  'update:modelValue': [value: string | null];
  'select': [place: PlaceRow];
}>();

useI18n();
const query = ref('');
const results = ref<PlaceRow[]>([]);
const showDropdown = ref(false);
let debounceTimer: ReturnType<typeof setTimeout>;

watch(() => props.modelValue, async (id) => {
  if (!id) { query.value = ''; return; }
  const place = (await window.api.places.get(id)) as PlaceRow | null;
  if (place) query.value = place.name;
}, { immediate: true });

function onInput() {
  clearTimeout(debounceTimer);
  if (query.value.length < 1) { results.value = []; return; }
  debounceTimer = setTimeout(async () => {
    results.value = (await window.api.places.search(query.value)) as PlaceRow[];
  }, 150);
}

function select(place: PlaceRow) {
  query.value = place.name;
  showDropdown.value = false;
  emit('update:modelValue', place.id);
  emit('select', place);
}

async function createNew() {
  const place = (await window.api.places.findOrCreate(query.value)) as PlaceRow;
  select(place);
}

function onBlur() {
  setTimeout(() => { showDropdown.value = false; }, 150);
}
</script>
```

```vue
import { useRouter } from 'vue-router';
import { useI18n } from 'vue-i18n';
import { PLACE_TYPE_VALUES } from '../constants/eventTypes';

declare const window: Window & {
  api: Record<string, Record<string, (...args: unknown[]) => Promise<unknown>>>;
};

interface PlaceRow { id: string; name: string; place_type: string | null; }

useI18n();
const router = useRouter();
const places = ref<PlaceRow[]>([]);
const showAddForm = ref(false);
const newPlace = reactive({ name: '', place_type: '' });

async function load() {
  places.value = (await window.api.places.list()) as PlaceRow[];
}

async function addPlace() {
  await window.api.places.create({
    name: newPlace.name,
    place_type: newPlace.place_type || null,
  });
  showAddForm.value = false;
  Object.assign(newPlace, { name: '', place_type: '' });
  await load();
}

async function deletePlace(id: string) {
  await window.api.places.delete(id);
  await load();
}

onMounted(load);
</script>
```

```vue
        </label>
        <label>{{ $t('places.longitude') }}
          <input v-model.number="editLon" type="number" step="0.000001" @blur="save({ longitude: editLon || null })" />
        </label>
      </div>
    </section>

    <section class="detail-section">
      <h4>{{ $t('common.notes') }}</h4>
      <textarea v-model="editNotes" rows="3" @blur="save({ notes: editNotes })" />
    </section>

    <section v-if="children.length" class="detail-section">
      <h4>{{ $t('places.childPlaces') }}</h4>
      <ul class="child-list">
        <li v-for="child in children" :key="child.id">
          <a @click.prevent="$router.push('/places/' + child.id)">{{ child.name }}</a>
          <span v-if="child.place_type" class="type-badge">{{ $t('placeTypes.' + child.place_type) }}</span>
        </li>
      </ul>
    </section>
  </div>
  <div v-else class="empty">{{ $t('common.loading') }}</div>

<script setup lang="ts">
import { ref, onMounted } from 'vue';
import { useRoute } from 'vue-router';
import { useI18n } from 'vue-i18n';
import PlacePicker from '../components/PlacePicker.vue';
import { PLACE_TYPE_VALUES } from '../constants/eventTypes';

declare const window: Window & {
  api: Record<string, Record<string, (...args: unknown[]) => Promise<unknown>>>;
};

interface PlaceRow { id: string; name: string; place_type: string | null; parent_place_id: string | null; latitude: number | null; longitude: number | null; notes: string; }

useI18n();
const route = useRoute();
const placeId = route.params.id as string;
const place = ref<PlaceRow | null>(null);
const children = ref<PlaceRow[]>([]);
const editName = ref('');
const editType = ref('');
const editParentId = ref<string | null>(null);
const editLat = ref<number | null>(null);
const editLon = ref<number | null>(null);
const editNotes = ref('');

async function load() {
  place.value = (await window.api.places.get(placeId)) as PlaceRow | null;
  if (!place.value) return;
  editName.value = place.value.name;
  editType.value = place.value.place_type ?? '';
  editParentId.value = place.value.parent_place_id;
  editLat.value = place.value.latitude;
  editLon.value = place.value.longitude;
  editNotes.value = place.value.notes;
  // Load children: places where parent_place_id = this place
  const all = (await window.api.places.list()) as PlaceRow[];
  children.value = all.filter(p => p.parent_place_id === placeId);
}

async function save(data: Record<string, unknown>) {
  await window.api.places.update(placeId, data);
  await load();
}

onMounted(load);
</script>
```
