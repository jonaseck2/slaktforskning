# i18n Coverage Fix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace all hardcoded Swedish (and untranslated) strings in renderer components with `$t()` calls, so the English language mode works correctly throughout the app.

**Architecture:** Add missing keys to `en.ts` and `sv.ts`, then replace hardcoded strings in six components. No structural changes.

**Tech Stack:** vue-i18n, `src/renderer/i18n/en.ts`, `src/renderer/i18n/sv.ts`

### Task 3: Fix PersonPanel.vue

**Files:**
- Modify: `src/renderer/components/PersonPanel.vue`

- [ ] **Step 1: Ensure useI18n is imported**

In `<script setup>`, verify:
```typescript
import { useI18n } from 'vue-i18n';
const { t } = useI18n();
```

If `useI18n` is imported but `t` not destructured, add it.

- [ ] **Step 2: Replace hardcoded strings in template**

For each hardcoded string in the template, replace with `$t()`:

```vue
<!-- Before -->
<button>+ Förälder</button>
<!-- After -->
<button>{{ $t('personDetail.addParent') }}</button>

<!-- Before -->
<button>+ Partner</button>
<!-- After -->
<button>{{ $t('personDetail.addSpouse') }}</button>

<!-- Before -->
<button>+ Barn</button>
<!-- After -->
<button>{{ $t('personDetail.addChild') }}</button>

<!-- Before -->
<button>Redigera</button>
<!-- After -->
<button>{{ $t('common.edit') }}</button>

<!-- Before -->
<span>Kön</span>
<!-- After -->
<span>{{ $t('persons.sex') }}</span>

<!-- Before -->
<span>Status</span>
<!-- After -->
<span>{{ $t('personPanel.status') }}</span>
```
