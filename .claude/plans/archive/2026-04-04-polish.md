# Feature: Polish

## Summary
Added Escape key support to all modals and data backup/restore functionality.

## Changes

### Escape key
All modal components (EventForm, CitationForm, AddRelatedPersonModal) and inline modals in view components close when the user presses Escape, via window keydown listener mounted/unmounted with the component.

Views with inline modals handled:
- PersonsView (showAddForm)
- RelationshipsView (showAddForm)
- SourcesView (showAddForm)
- PlacesView (showAddForm)
- PersonDetailView (showNameForm, showEditNameForm, showAddIdentifier, showCitePersonForm)

### Data Backup/Restore
- `backup:backup` IPC: copies the active SQLite file to a user-selected path via dialog.showSaveDialog
- `backup:restore` IPC: opens a file picker, calls switchDatabase() to load the backup, sends db:switched to all windows
- `window.api.backup.backup()` / `window.api.backup.restore()` in preload
- DatabaseView.vue: Backup and Restore buttons with status feedback (auto-clears after 5s)

## Deferred

- Full keyboard navigation (needs its own plan)
