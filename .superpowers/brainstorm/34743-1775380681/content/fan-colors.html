Fan Chart: Color scheme?

Each option uses muted, readable tones. Same 360° layout — 4 generations shown. Pick what feels right.

A — Kön (blå/rosa)

Matchar befintliga träd i appen. Blå = man, rosa = kvinna. Tydlig signal per person, konsekvent med pedigree-vyn.

B — Generation (ring per ring)

Varje generationsring får en egen ton. Tydlig djupkänsla. Bakgrundsfärg hjälper läsaren förstå hur långt tillbaka de är.

C — Gren (farfar/farmor/morfar/mormor)

Fyra färger, en per farföräldragren. Lätt att se varifrån varje anfader härstammar. Lik Rogers-exempelbilden.

Alternativ B (generation) och C (gren) är vanligast i moderna genealogiprogram.
