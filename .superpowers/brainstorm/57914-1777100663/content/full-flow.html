Design rules in this flow
📅 Event owns: type, date, place — nothing else
🔗 Citation owns: page, confidence, transcription
👤 Person owns: name, sex — life events are just Event entities
📚 Source owns: title, type, author, repository

Section headers = entity card header aesthetic (flush, rounded top, entity color)
