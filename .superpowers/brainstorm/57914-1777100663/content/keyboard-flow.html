Tab order per panel
Person: Given → Surname → Sex (← →) → Living (space) → ↩ Save
Event: Type (← →) → Date → Place → Notes → ↩ Save
Citation: Source → Page → Confidence (← →) → Transcription → ↩ Save

Event type is a segmented control
Left/right arrows cycle through all event types (Birth, Baptism, Marriage, Emigration, Death…). Any event can be added to any person — no hardcoded Born/Died fields.

Pickers are keyboard-native
Type to search, ↑↓ to navigate results, ↩ to confirm. Last result is always "+ Create …" — ↩ on it opens the sub-panel and focuses its first field automatically.
