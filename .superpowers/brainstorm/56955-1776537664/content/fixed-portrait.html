Sizing Rule

Portrait: fixed 34×44px, vertically centered, rounded 4px corners.
Box height: max(portrait + padding, text + padding) — so the portrait sets a minimum height of ~58px even when text is minimal, and the box grows beyond that only when text wraps enough to exceed it.
