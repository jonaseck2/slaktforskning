Full Tree Visual Overhaul

Current pedigree tree vs. proposed redesign — boxes, connectors, spacing

Current — 155×54px boxes, straight lines, no photos/places
Proposed — 200×60px boxes, curved connectors, avatars, places

What Changed

Person Boxes
  • 200×60px (was 155×54)
  • Avatar circle (30px) with initials or photo
  • Full name with CSS ellipsis (no 20-char cut)
  • Compact dates: * 1938 – † 2014
  • Birth place as 3rd line
  • Subtle drop shadow
  • rx=6 radius (was 4)
Connectors & Layout
  • Curved elbow paths (SVG <path>)
  • Q-bezier rounded corners (10px radius)
  • Softer connector color (theme-aware)
  • H_GAP 60px (was 50) for breathing room
  • V_GAP 24px (was 20)
  • GEN_GAP 70px (was 60)
Data Pipeline Changes

PersonNode gets 3 new fields: birthPlace, deathPlace, photoUrl.
fetchPersonNode() fetches birth event place + profile media in parallel.
Photo: first media_links item for the person (sort_order=0) → file_ref path.
Place: from birth event's place_id → getPlace() → name.
