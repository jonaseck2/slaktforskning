Dynamic Box Height

Box height adapts to content. Fixed width (200px), variable height:

Name only ~38px rare edge case
1-line name + birth ~50px living person, short name
1-line name + birth + death ~64px most common
2-line name + birth + death ~78px long Swedish names

Layout impact: The layout algorithm must measure each box height before placement. Currently BOX_H = 54 is a constant — this becomes a per-node value computed during a measurement pass. The avatar circle vertically centers within the box regardless of height.
