How It Works in SVG

SVG <text> doesn't wrap natively. Two approaches:

  • Pre-measure + manual tspans: Measure name width with a canvas context, split into lines, compute box height before layout. Each line is a <tspan>. The portrait rect height = box height minus padding.
  • foreignObject: Embed an HTML <div> inside the SVG box. Gets native text wrapping for free. Requires a pre-measurement pass to know the rendered height for layout.

Either way, the layout algorithm gets a measurement pass that computes each node's height before placement. The portrait photo area uses the same height as the text content (minus top/bottom padding), creating the taller-than-wide aspect ratio naturally.
