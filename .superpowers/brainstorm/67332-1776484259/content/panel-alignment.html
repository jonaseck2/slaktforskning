Unified Rules (all three panels)

Hosting (parent view)
  • Same background — panel is white, same as content area, separated by drag handle only
  • No colored border-left — the green background peeking through the gap is the separator
  • Drag resize on all three — via usePanelResize() composable
  • Toggle ✕ to close — click entity again to reopen, or ✕ in panel header
  • Width persisted per view — separate localStorage keys
  • Default width: 300px, min 200px, max 50%
Panel internals
  • Header: avatar/thumbnail + name + summary + ✕ close
  • Quick actions: + Label buttons (never "Link Label")
  • Sections: all use SectionHeader with + Add action
  • Collapsed when empty: sections with count 0 start collapsed
  • Section state: single composable usePanelSections()
  • Content rows: left border-line + compact text
