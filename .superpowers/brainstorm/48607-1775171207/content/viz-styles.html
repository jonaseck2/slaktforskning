Visualization Styles

Which visualization paradigm fits the Släktforskning data model? The model has persons connected by typed relationships (couple, parent/child, sibling, godparent, other) — not a strict family-tree hierarchy. Select any that interest you.

A

Pedigree / Ancestor Chart

Classic genealogy view. Focal person on the left, parents branch right, grandparents further right. Traditional binary tree following parent_child relationships upward.

You ──── Father ──── Paternal GF
                     └─── Paternal GM
     └── Mother ──── Maternal GF
                     └─── Maternal GM

Pros

  • Instantly recognizable to researchers
  • Great for showing direct lineage

Cons

  • Only shows ancestors, not all relationships
  • Doesn't use sibling/godparent/other edges
B

Hourglass / Bowtie Chart

Focal person in the center. Ancestors expand upward; descendants expand downward. Combines pedigree + descendant in one view.

GF    GM    GF    GM
  └─── Dad    Mom ───┘
          │
        You
          │
    Child1   Child2

Pros

  • Shows full lineage in one view
  • Intuitive for researchers

Cons

  • Still mostly parent/child focused
  • Gets cluttered with many generations
C

Network / Force-Directed Graph

Persons as nodes, all relationships as edges with labels. Siblings, godparents, "other" relationships all appear. Full use of the data model. Uses a physics simulation to lay out the graph.

   [GF]───couple───[GM]
          │ parent_child
[Uncle]─sibling─[Dad]──couple──[Mom]
                │ parent_child
         [You]─sibling─[Sibling]
           │ godparent
        [Godparent]

Pros

  • Fully exploits all relationship types
  • Natural for a graph data model
  • Reveals unexpected connections

Cons

  • Can become a "hairball" with many nodes
  • Less readable than structured charts
  • Layout is non-deterministic
D

Timeline / Chronological View

Persons or events plotted on a horizontal time axis. Great for understanding when people lived, overlapping generations, and event clustering.

1800    1850    1900    1950
─────┬──────────┬──────────┬─────
     [─── GF ────]
              [────── Dad ──────]
                      [── You ──→

Pros

  • Shows temporal context researchers care about
  • Easy to see generation overlaps
  • Works for event-heavy research

Cons

  • Doesn't show relationships directly
  • Requires good date data
