How the theme system works

  • CSS custom properties — all colors defined as variables on :root, swapped by theme class
  • Three themes: Forest (green), Nordic (blue), Twilight (purple)
  • Same components — buttons, badges, avatars, tables all reference the same variable names
  • Theme switcher — small color dots in sidebar footer (or Settings), persisted to localStorage
  • Existing Light/Dark/Contrast modes become orthogonal — theme = color palette, mode = brightness
  • Sex badges stay gendered colors (pink/blue) across all themes — they're semantic, not themed
  • Warmer content background (#faf8f5 instead of pure white) across all themes
