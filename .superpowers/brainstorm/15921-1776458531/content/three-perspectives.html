The Pattern

👤
People
Tree chart → PersonPanel
Add events, relationships,
media, sources
📍
Places
Map → PlacePanel
See events, persons,
citations at place
📷
Media
Gallery → MediaPanel
Link persons, events,
places, face tags
  • Same interaction pattern — spatial view on left, detail panel on right, click to select
  • Panel is the workbench — all entity linking happens in the panel, not in the main view
  • Lightbox stays clean — just navigation and viewing, no editing cluttering the experience
  • Face tags in MediaPanel — naturally solves where region tagging UI lives
  • Cross-linking — click a person in MediaPanel → opens PersonPanel in tree. Click media in PersonPanel → opens lightbox. Everything connects.
