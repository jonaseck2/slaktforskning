High: Missing Visual Feedback

  • No loading spinners — most views show "Loading..." text or nothing during data fetch
  • No progress indicators for import/export operations
  • Errors disappear — toast notifications vanish with no retry option
  • No skeleton screens — person detail shows blank then jumps to content

Medium: Inconsistent Design Language

  • Sex badges use hardcoded hex colors instead of CSS variables
  • Quality severity badges use different color approach than sex badges
  • Some views show counts in header, others don't
  • Empty state messages inconsistent — singular vs plural, different phrasing
  • Form validation is "required" attribute only — no inline error messages

Medium: Person Detail Complexity

  • PersonDetailView is the most visited screen but has no visual hierarchy — all sections look equal
  • Profile placeholder uses text symbols (♀/♂/?) instead of proper icons
  • No photo/avatar prominence — media section buried among many sections
  • Notes field auto-saves on blur but gives no visual confirmation

Low: No Responsive Design

  • Sidebar is fixed 220px — no collapse for narrow windows
  • Tables overflow horizontally on small screens
  • No min-width constraint — app can be resized to unusable widths
  • Acceptable for desktop-first Electron app, but worth noting
