# GEDCOM 5.5.1 Import/Export

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement GEDCOM 5.5.1 import and export so the app can exchange family tree data with any major genealogy platform (Ancestry, FamilySearch, MyHeritage, Gramps, etc.).

**Architecture:** A `src/gedcom/` module handles all GEDCOM logic: a line-by-line parser, an importer that maps GEDCOM records to API calls, and an exporter that queries the DB and generates a `.ged` string. The Electron main process exposes import/export via IPC (file dialogs). The MCP server exposes `import_gedcom` and `export_gedcom` tools. No GEDCOM logic leaks into the API layer — `src/api/` stays pure.

**Dependencies:** This plan depends on **v0.4.0 Places** being complete, because PLAC tags on import create place records via `findOrCreatePlace()`.

**Tech Stack:** TypeScript, node-sqlite3-wasm, Electron dialog API for file picking, `read-gedcom` npm package for parsing (browser + Node compatible).

## GEDCOM-X vs GEDCOM 5.5.1: What This App Covers

The internal data model is conceptually inspired by GEDCOM-X. Here is how GEDCOM 5.5.1 maps to it:

### What maps cleanly

| GEDCOM 5.5.1 | App entity | Notes |
|---|---|---|
| `INDI` | `persons` | Direct |
| `INDI.SEX` | `persons.sex` | M/F/U |
| `INDI.NAME` | `person_names` | Parse `Given /Surname/` format |
| `INDI.NAME.NPFX` | `person_names.name_prefix` | Requires v0.3.1 |
| `INDI.NAME.NSFX` | `person_names.name_suffix` | Requires v0.3.1 |
| `INDI.REFN` | `person_identifiers` (type=`refn`) | Requires v0.3.1 |
| `INDI.RIN` | `person_identifiers` (type=`rin`) | Requires v0.3.1 |
| `INDI.BIRT/DEAT/CHR/BURI/...` | `events` + `event_participants` | role=`primary` |
| `FAM` | `relationships` (type=`couple`) | HUSB=person1, WIFE=person2 |
| `FAM.CHIL` | `relationships` (type=`parent_child`) | Both parents via couple rel |
| `FAM.MARR/DIV/...` | `events` linked via `relationship_id` | role=`spouse` for participants |
| `PLAC` | `places` via `findOrCreatePlace()` | Hierarchical string stored as-is |
| `SOUR` (level 0) | `sources` | title/author/publication_info |
| `SOUR` (inline citation) | `citations` | QUAY→confidence, PAGE→page, DATA.TEXT→transcription |
| `DATE` | `events.date_type` + `date_value` + `date_original` | See date parsing table |
| `NOTE` | `persons.notes`, `events.description` | Concatenate CONT/CONC lines |
| `INDI.OCCU/RESI/EDUC/...` | `events` with matching `event_type` | |
| `FAM.DIV` | `events` (type=`divorce`) with `relationship_id` | |

### What gets dropped (not in app model)

| GEDCOM tag | Reason dropped |
|---|---|
| `REPO` record | Repository is just a text field on sources. Future: could become its own entity. |
| `SUBM` record | No submitter concept in app. |
| `OBJE` / multimedia | No media attachments (planned v0.6.0). |
| `ASSO` (associations) | No general association concept. |
| `ALIA` | No alias identity linking. |
| LDS ordinances (`BAPL`, `SLGC`, etc.) | Not relevant for Swedish genealogy. |
| `ANCI`/`DESI` | Researcher flags, no equivalent. |
| `AFN`/`RFN` | Could be stored as person_identifiers but rarely used in Swedish trees. |
| `_` prefixed custom tags | Silently dropped. |

### Date mapping

| GEDCOM date string | date_type | date_value | date_value_end |
|---|---|---|---|
| `12 JUN 1845` | `exact` | `1845-06-12` | null |
| `JUN 1845` | `exact` | `1845-06` | null |
| `1845` | `exact` | `1845` | null |
| `ABT 1845` / `CAL 1845` / `EST 1845` | `about` | `1845` | null |
| `BEF 1850` | `before` | `1850` | null |
| `AFT 1840` | `after` | `1840` | null |
| `BET 1840 AND 1850` | `between` | `1840` | `1850` |
| `FROM 1840 TO 1850` | `between` | `1840` | `1850` |
| Any other string | `unknown` | null | null |

Always store the original GEDCOM date string in `date_original`.

```typescript
// src/gedcom/parser.ts
export interface GedcomNode {
  level: number;
  xref: string | null;    // e.g. "@I1@"
  tag: string;            // e.g. "INDI", "NAME"
  value: string;          // e.g. "John /Smith/"
  children: GedcomNode[];
}

export function parseGedcom(text: string): GedcomNode[] {
  const lines = text.replace(/\r\n/g, '\n').replace(/\r/g, '\n').split('\n');
  const root: GedcomNode[] = [];
  const stack: GedcomNode[] = [];

  for (const raw of lines) {
    const line = raw.trim();
    if (!line) continue;

    // Format: LEVEL [XREF] TAG [VALUE]
    const match = line.match(/^(\d+)\s+(@[^@]+@)?\s*(\w+)\s*(.*)?$/);
    if (!match) continue;

    const level = parseInt(match[1], 10);
    const xref = match[2]?.trim() ?? null;
    const tag = match[3].trim();
    let value = (match[4] ?? '').trim();

    // Handle CONC — concatenate to previous sibling's value
    if (tag === 'CONC' && stack.length > 0) {
      const parent = stack[stack.length - 1];
      if (parent.children.length > 0) {
        parent.children[parent.children.length - 1].value += value;
      }
      continue;
    }

    const node: GedcomNode = { level, xref, tag, value, children: [] };

    // CONT — append with newline
    if (tag === 'CONT' && stack.length > 0) {
      const parent = stack[stack.length - 1];
      if (parent.children.length > 0) {
        parent.children[parent.children.length - 1].value += '\n' + value;
      }
      continue;
    }

    // Pop stack until we're at the right parent level
    while (stack.length > 0 && stack[stack.length - 1].level >= level) {
      stack.pop();
    }

    if (stack.length === 0) {
      root.push(node);
    } else {
      stack[stack.length - 1].children.push(node);
    }
    stack.push(node);
  }

  return root;
}
```

```typescript
// src/gedcom/date.ts
const MONTHS: Record<string, string> = {
  JAN: '01', FEB: '02', MAR: '03', APR: '04', MAY: '05', JUN: '06',
  JUL: '07', AUG: '08', SEP: '09', OCT: '10', NOV: '11', DEC: '12',
};

function parseDate(s: string): string | null {
  s = s.trim().toUpperCase();
  // DD MON YYYY
  const dmy = s.match(/^(\d{1,2})\s+([A-Z]{3})\s+(\d{4})$/);
  if (dmy) return `${dmy[3]}-${MONTHS[dmy[2]] ?? '01'}-${dmy[1].padStart(2, '0')}`;
  // MON YYYY
  const my = s.match(/^([A-Z]{3})\s+(\d{4})$/);
  if (my) return `${my[2]}-${MONTHS[my[1]] ?? '01'}`;
  // YYYY
  const y = s.match(/^(\d{4})$/);
  if (y) return y[1];
  return null;
}

export interface ParsedDate {
  date_type: 'exact' | 'about' | 'before' | 'after' | 'between' | 'calculated' | 'unknown';
  date_value: string | null;
  date_value_end: string | null;
  date_original: string;
}

export function parseGedcomDate(raw: string): ParsedDate {
  const s = raw.trim().toUpperCase();
  const orig = raw.trim();

  const bet = s.match(/^BET\s+(.+)\s+AND\s+(.+)$/);
  if (bet) return { date_type: 'between', date_value: parseDate(bet[1]), date_value_end: parseDate(bet[2]), date_original: orig };

  const from = s.match(/^FROM\s+(.+)\s+TO\s+(.+)$/);
  if (from) return { date_type: 'between', date_value: parseDate(from[1]), date_value_end: parseDate(from[2]), date_original: orig };

  if (s.startsWith('BEF ')) return { date_type: 'before', date_value: parseDate(s.slice(4)), date_value_end: null, date_original: orig };
  if (s.startsWith('AFT ')) return { date_type: 'after', date_value: parseDate(s.slice(4)), date_value_end: null, date_original: orig };
  if (s.startsWith('ABT ') || s.startsWith('CAL ') || s.startsWith('EST '))
    return { date_type: 'about', date_value: parseDate(s.slice(4)), date_value_end: null, date_original: orig };

  const exact = parseDate(s);
  if (exact) return { date_type: 'exact', date_value: exact, date_value_end: null, date_original: orig };

  return { date_type: 'unknown', date_value: null, date_value_end: null, date_original: orig };
}
```

```typescript
// src/gedcom/importer.ts
import { Database } from 'node-sqlite3-wasm';
import { GedcomNode } from './parser';
import { parseGedcomDate } from './date';
import { createPerson, addPersonName, getPersonIdentifiers, addPersonIdentifier } from '../api/persons';
import { createRelationship } from '../api/relationships';
import { createEvent, addEventParticipant } from '../api/events'; // adjust actual exports
import { createSource, createCitation } from '../api/sources';
import { findOrCreatePlace } from '../api/places';

export function importGedcom(db: Database, tree: GedcomNode[]): void {
  // Phase 1: SOUR records → sources map
  const sourceMap = new Map<string, string>(); // xref → app source id
  for (const node of tree) {
    if (node.tag !== 'SOUR' || !node.xref) continue;
    const src = createSource(db, {
      title: node.children.find(c => c.tag === 'TITL')?.value ?? '',
      author: node.children.find(c => c.tag === 'AUTH')?.value ?? '',
      publication_info: node.children.find(c => c.tag === 'PUBL')?.value ?? '',
      repository: node.children.find(c => c.tag === 'REPO')?.value ?? '',
    });
    sourceMap.set(node.xref, src.id);
  }

  // Phase 2: INDI records → persons map
  const personMap = new Map<string, string>(); // xref → app person id
  for (const node of tree) {
    if (node.tag !== 'INDI' || !node.xref) continue;
    const sex = (node.children.find(c => c.tag === 'SEX')?.value ?? 'U') as 'M' | 'F' | 'U';
    const notes = node.children.find(c => c.tag === 'NOTE')?.value ?? '';
    const person = createPerson(db, { sex, notes });
    personMap.set(node.xref, person.id);

    // Names
    for (const nameNode of node.children.filter(c => c.tag === 'NAME')) {
      const raw = nameNode.value ?? '';
      // "Given /Surname/" or "Given /Surname/ Suffix"
      const surnameMatch = raw.match(/^(.*?)\/(.+?)\/(.*)?$/);
      const given = (surnameMatch?.[1] ?? raw).trim() || null;
      const surname = surnameMatch?.[2]?.trim() || null;
      const prefix = nameNode.children.find(c => c.tag === 'NPFX')?.value ?? null;
      const suffix = nameNode.children.find(c => c.tag === 'NSFX')?.value ?? null;
      const nameType = nameNode.children.find(c => c.tag === 'TYPE')?.value;
      addPersonName(db, person.id, {
        given_name: given,
        surname,
        name_prefix: prefix,
        name_suffix: suffix,
        name_type: nameType === 'MARRIED' ? 'married' : nameType === 'AKA' ? 'aka' : 'birth',
      });
    }

    // REFN / RIN identifiers
    for (const refn of node.children.filter(c => c.tag === 'REFN')) {
      addPersonIdentifier(db, person.id, { identifier_type: 'refn', identifier_value: refn.value });
    }
    const rin = node.children.find(c => c.tag === 'RIN');
    if (rin?.value) addPersonIdentifier(db, person.id, { identifier_type: 'rin', identifier_value: rin.value });

    // Person events (BIRT, DEAT, CHR, BURI, OCCU, RESI, etc.)
    const personEventTags: Record<string, string> = {
      BIRT: 'birth', DEAT: 'death', CHR: 'christening', BURI: 'burial',
      BAPM: 'baptism', CONF: 'confirmation', OCCU: 'occupation',
      RESI: 'residence', EDUC: 'education', EMIG: 'emigration',
      IMMI: 'immigration', NATU: 'naturalization', CENS: 'census',
      PROB: 'probate', WILL: 'will', GRAD: 'graduation', RETI: 'retirement',
      EVEN: 'other',
    };
    for (const [gedTag, appType] of Object.entries(personEventTags)) {
      for (const evNode of node.children.filter(c => c.tag === gedTag)) {
        const dateNode = evNode.children.find(c => c.tag === 'DATE');
        const placeName = evNode.children.find(c => c.tag === 'PLAC')?.value;
        const parsed = dateNode ? parseGedcomDate(dateNode.value) : { date_type: 'unknown' as const, date_value: null, date_value_end: null, date_original: '' };
        const place = placeName ? findOrCreatePlace(db, placeName) : null;
        const event = createEvent(db, {
          event_type: appType,
          date_type: parsed.date_type,
          date_value: parsed.date_value,
          date_value_end: parsed.date_value_end,
          date_original: parsed.date_original,
          place_id: place?.id ?? null,
          description: evNode.children.find(c => c.tag === 'NOTE')?.value ?? '',
        });
        addEventParticipant(db, { event_id: event.id, person_id: person.id, role: 'primary' });

        // Inline source citations on this event
        for (const sour of evNode.children.filter(c => c.tag === 'SOUR')) {
          const srcId = sourceMap.get(sour.value) ?? sourceMap.get(sour.xref ?? '');
          if (srcId) {
            const quay = parseInt(sour.children.find(c => c.tag === 'QUAY')?.value ?? '2', 10);
            const page = sour.children.find(c => c.tag === 'PAGE')?.value;
            const text = sour.children.find(c => c.tag === 'DATA')?.children.find(c => c.tag === 'TEXT')?.value;
            createCitation(db, { source_id: srcId, event_id: event.id, person_id: person.id, page: page ?? '', confidence: Math.min(3, Math.max(0, quay)), transcription: text ?? '' });
          }
        }
      }
    }
  }

  // Phase 3: FAM records → relationships
  for (const node of tree) {
    if (node.tag !== 'FAM') continue;
    const husbXref = node.children.find(c => c.tag === 'HUSB')?.value;
    const wifeXref = node.children.find(c => c.tag === 'WIFE')?.value;
    const person1Id = husbXref ? personMap.get(husbXref) : null;
    const person2Id = wifeXref ? personMap.get(wifeXref) : null;

    // Couple relationship
    const couple = createRelationship(db, {
      type: 'couple',
      person1_id: person1Id ?? null,
      person2_id: person2Id ?? null,
      subtype: 'unknown',
    });

    // Family events (MARR, DIV, etc.)
    const familyEventTags: Record<string, string> = {
      MARR: 'marriage', DIV: 'divorce', CENS: 'census', EVEN: 'other',
    };
    for (const [gedTag, appType] of Object.entries(familyEventTags)) {
      for (const evNode of node.children.filter(c => c.tag === gedTag)) {
        const dateNode = evNode.children.find(c => c.tag === 'DATE');
        const placeName = evNode.children.find(c => c.tag === 'PLAC')?.value;
        const parsed = dateNode ? parseGedcomDate(dateNode.value) : { date_type: 'unknown' as const, date_value: null, date_value_end: null, date_original: '' };
        const place = placeName ? findOrCreatePlace(db, placeName) : null;
        createEvent(db, {
          event_type: appType,
          date_type: parsed.date_type,
          date_value: parsed.date_value,
          date_value_end: parsed.date_value_end,
          date_original: parsed.date_original,
          place_id: place?.id ?? null,
          relationship_id: couple.id,
          description: evNode.children.find(c => c.tag === 'NOTE')?.value ?? '',
        });
      }
    }

    // Children → parent_child relationships
    for (const chil of node.children.filter(c => c.tag === 'CHIL')) {
      const childId = personMap.get(chil.value);
      if (!childId) continue;
      if (person1Id) createRelationship(db, { type: 'parent_child', person1_id: person1Id, person2_id: childId, subtype: 'biological' });
      if (person2Id) createRelationship(db, { type: 'parent_child', person1_id: person2Id, person2_id: childId, subtype: 'biological' });
    }
  }
}
```

Key design: assign stable XREF IDs by hashing the UUID. Use a Map from `app_id → xref_id`.

```typescript
// src/gedcom/exporter.ts
import { Database } from 'node-sqlite3-wasm';
import { listPersons, getPersonNames, getPersonIdentifiers } from '../api/persons';
import { listRelationships, getRelationshipsOfPerson } from '../api/relationships';
import { getEventsForPerson, getEventsForRelationship, getEventParticipants } from '../api/events';
import { listSources, getCitationsForEvent } from '../api/sources';
import { getPlace } from '../api/places';

function xref(prefix: string, index: number): string {
  return `@${prefix}${index}@`;
}

function formatDate(date_type: string, date_value: string | null, date_value_end: string | null, date_original: string): string {
  if (date_original) return date_original; // Preserve original format
  if (!date_value) return '';
  if (date_type === 'about') return `ABT ${date_value}`;
  if (date_type === 'before') return `BEF ${date_value}`;
  if (date_type === 'after') return `AFT ${date_value}`;
  if (date_type === 'between' && date_value_end) return `BET ${date_value} AND ${date_value_end}`;
  return date_value.replace(/-/g, ' ').split(' ').map((p, i) => {
    if (i === 1) return ['JAN','FEB','MAR','APR','MAY','JUN','JUL','AUG','SEP','OCT','NOV','DEC'][parseInt(p,10)-1] ?? p;
    return p;
  }).join(' ');
}

const EVENT_TYPE_TO_TAG: Record<string, string> = {
  birth: 'BIRT', death: 'DEAT', christening: 'CHR', burial: 'BURI',
  baptism: 'BAPM', confirmation: 'CONF', occupation: 'OCCU',
  residence: 'RESI', education: 'EDUC', emigration: 'EMIG',
  immigration: 'IMMI', naturalization: 'NATU', census: 'CENS',
  probate: 'PROB', will: 'WILL', graduation: 'GRAD', retirement: 'RETI',
  marriage: 'MARR', divorce: 'DIV', other: 'EVEN',
};

export function exportGedcom(db: Database): string {
  const lines: string[] = [];

  lines.push('0 HEAD', '1 GEDC', '2 VERS 5.5.1', '1 CHAR UTF-8');

  // Sources
  const sources = listSources(db);
  const sourceXref = new Map<string, string>();
  sources.forEach((src, i) => {
    const xr = xref('S', i + 1);
    sourceXref.set(src.id, xr);
    lines.push(`0 ${xr} SOUR`);
    if (src.title) lines.push(`1 TITL ${src.title}`);
    if (src.author) lines.push(`1 AUTH ${src.author}`);
    if (src.publication_info) lines.push(`1 PUBL ${src.publication_info}`);
  });

  // Persons
  const persons = listPersons(db);
  const personXref = new Map<string, string>();
  persons.forEach((p, i) => {
    const xr = xref('I', i + 1);
    personXref.set(p.id, xr);
    lines.push(`0 ${xr} INDI`);
    const names = getPersonNames(db, p.id);
    for (const n of names) {
      const given = n.given_name ?? '';
      const sur = n.surname ? `/${n.surname}/` : '';
      let nameStr = `${given} ${sur}`.trim();
      lines.push(`1 NAME ${nameStr}`);
      if (n.name_prefix) lines.push(`2 NPFX ${n.name_prefix}`);
      if (n.name_suffix) lines.push(`2 NSFX ${n.name_suffix}`);
    }
    lines.push(`1 SEX ${p.sex}`);
    if (p.notes) lines.push(`1 NOTE ${p.notes}`);

    // Person events
    const events = getEventsForPerson(db, p.id);
    for (const ev of events) {
      if (ev.relationship_id) continue; // family events handled below
      const tag = EVENT_TYPE_TO_TAG[ev.event_type] ?? 'EVEN';
      const dateStr = formatDate(ev.date_type, ev.date_value, ev.date_value_end, ev.date_original);
      lines.push(`1 ${tag}`);
      if (dateStr) lines.push(`2 DATE ${dateStr}`);
      if (ev.place_id) {
        const place = getPlace(db, ev.place_id);
        if (place) lines.push(`2 PLAC ${place.name}`);
      }
      // Citations
      const citations = getCitationsForEvent(db, ev.id);
      for (const cit of citations) {
        const srcXr = sourceXref.get(cit.source_id);
        if (srcXr) {
          lines.push(`2 SOUR ${srcXr}`);
          if (cit.page) lines.push(`3 PAGE ${cit.page}`);
          lines.push(`3 QUAY ${cit.confidence}`);
          if (cit.transcription) lines.push(`3 DATA`, `4 TEXT ${cit.transcription}`);
        }
      }
    }

    // Identifiers
    const identifiers = getPersonIdentifiers(db, p.id);
    for (const ident of identifiers) {
      if (ident.identifier_type === 'refn') lines.push(`1 REFN ${ident.identifier_value}`);
      if (ident.identifier_type === 'rin') lines.push(`1 RIN ${ident.identifier_value}`);
    }
  });

  // Families (couple relationships)
  const relationships = listRelationships(db);
  const couples = relationships.filter(r => r.type === 'couple');
  couples.forEach((rel, i) => {
    const xr = xref('F', i + 1);
    lines.push(`0 ${xr} FAM`);
    if (rel.person1_id) lines.push(`1 HUSB ${personXref.get(rel.person1_id) ?? ''}`);
    if (rel.person2_id) lines.push(`1 WIFE ${personXref.get(rel.person2_id) ?? ''}`);

    // Children
    const children = relationships.filter(r =>
      r.type === 'parent_child' &&
      (r.person1_id === rel.person1_id || r.person1_id === rel.person2_id)
    );
    const childIds = new Set(children.map(c => c.person2_id).filter(Boolean));
    for (const childId of childIds) {
      lines.push(`1 CHIL ${personXref.get(childId!) ?? ''}`);
    }

    // Family events
    const famEvents = getEventsForRelationship(db, rel.id);
    for (const ev of famEvents) {
      const tag = EVENT_TYPE_TO_TAG[ev.event_type] ?? 'EVEN';
      const dateStr = formatDate(ev.date_type, ev.date_value, ev.date_value_end, ev.date_original);
      lines.push(`1 ${tag}`);
      if (dateStr) lines.push(`2 DATE ${dateStr}`);
      if (ev.place_id) {
        const place = getPlace(db, ev.place_id);
        if (place) lines.push(`2 PLAC ${place.name}`);
      }
    }
  });

  lines.push('0 TRLR');
  return lines.join('\n') + '\n';
}
```

```typescript
// Import: open file dialog → read .ged → parse → import
wrapHandler('gedcom:import', async () => {
  const result = await dialog.showOpenDialog({
    title: 'Import GEDCOM File',
    filters: [{ name: 'GEDCOM Files', extensions: ['ged', 'gedcom'] }],
    properties: ['openFile'],
  });
  if (result.canceled || result.filePaths.length === 0) return { canceled: true };
  const text = fs.readFileSync(result.filePaths[0], 'utf-8');
  const tree = parseGedcom(text);
  importGedcom(getDatabase(), tree);
  return { imported: true, filePath: result.filePaths[0] };
});

// Export: generate .ged → save file dialog → write
wrapHandler('gedcom:export', async () => {
  const result = await dialog.showSaveDialog({
    title: 'Export GEDCOM File',
    defaultPath: 'family-tree.ged',
    filters: [{ name: 'GEDCOM Files', extensions: ['ged'] }],
  });
  if (result.canceled || !result.filePath) return { canceled: true };
  const gedText = exportGedcom(getDatabase());
  fs.writeFileSync(result.filePath, gedText, 'utf-8');
  return { exported: true, filePath: result.filePath };
});
```
